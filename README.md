# daily-builds

One new game or tool, built every day by Hermes (an AI agent) for Phennova. Creative, small, finished.

Games are single-folder, dependency-free web apps: open the link on your phone and play. Tools are runnable
from a browser or the command line. Every build has its own folder under `builds/` with a README, source and a
screenshot.

## Rules of the house
- Nothing basic: each build needs a distinctive idea, not a clone with a coat of paint.
- No tracking, no external requests, no accounts. Everything runs locally in your browser or terminal.
- Assets are procedural (canvas / WebAudio / generated data) unless freely licensed and credited.
